# KPA Bridge 3.0g (experimental)

**Experimental. Windows, Mac and Linux.** `Install_KPA_Bridge.bat` and the other `.bat` files are for **Windows**. **Mac and Linux** use `KPA_Bridge_v3.0g_Mac_Linux.zip` (see below). Tested by KW4EX on Windows 11 and on a Mac; Linux is less tested; a Raspberry Pi version has not been tested yet.

**KPA Bridge is essentially the KPA1500 SDR Bridge and the KPA1500 SmartSDR Bridge combined into one program.** One install for your **Elecraft KPA1500** with **Thetis, Thetis HL2, SDR-VST3, NereusSDR** and a **FlexRadio running SmartSDR** (the amplifier shows up there as a Power Genius XL and a Tuner Genius XL). Only one radio is on the air at a time; the amplifier follows the one in use. The two older bridges stay available.

**New in 3.0g**
- A program icon (`kpa_bridge.ico`), used by the **KPA Bridge** shortcuts the installer makes on the Desktop and in the Start menu (and optionally at Windows start-up).
- One shortcut starts and stops the bridge: if it is already running it asks "Stop it now? Y or N"; if not, it starts with no questions.
- Names made consistent: the program and its window are now called **KPA Bridge**; the files use underscores (`kpa_bridge.py`, `start_kpa_bridge.bat`, ...).
- The help and guide now explain the FlexRadio part and how the two kinds of radio work together.

**Update 3.0ga (same release, fixes after on-air testing with a FLEX-6300 and a Maestro)**
- The Applet header now shows the connected radio (Thetis or NereusSDR) and a Flex badge with the radio's model, name and callsign once it is logged in; it shows "searching" or the error when it is not.
- If the Flex does not answer, the bridge now waits longer between tries (5, 10, 20, 40, then 60 seconds) so it never floods the radio.
- The tuner's meter numbers are now corrected from the amplifier's connection, in case the radio numbers them differently.
- The Mac/Linux installer now also sets the FlexRadio login to "search for the radio" (it was left off).
- Good to know: if the PGXL or TGXL meter bars are empty on a Maestro after you restart the bridge, power-cycle the Maestro.

**Update 3.0ge (same release, found while testing a lost amplifier address)**
- The Flex tuner login no longer waits up to a minute to start. It was slowed down while waiting for the amplifier login.
- The Applet now shows **Amplifier not answering at ...** with a **Find amplifier** button when the amp can't be reached. If the search finds one amplifier at a different address, the bridge switches to it.
- The panel (Settings, Find amplifier) now says "FOUND an amplifier at ... click Use this address" instead of leaving the old "not responding" line.
- Good to know: if the amp loses its network address (its menu shows 0.0.0.0), restart the amp, then use **Find amplifier**. If your router can reserve an address for the amp, it keeps the same one every time.

**Highlights**
- The amp follows the radio that last changed frequency or transmitted. Starting SmartSDR does not move the amp away from your Thetis frequency.
- Over-drive protection for both kinds of radio, with a full-power setting for each.
- Software key that follows whichever radio transmits, including a Flex TUNE from a phone.
- Flex tuner C1/L bars, meters, quiet reconnect messages, status page at `http://127.0.0.1:8080/flex`.

Run only one bridge at a time; this one closes a running older KPA1500 bridge when it starts. Your old bridges are not changed.

## Mac and Linux

1. Look at the **Assets** list at the bottom of this page and click **KPA_Bridge_v3.0g_Mac_Linux.zip**. On a Mac it unzips by itself when you double-click it.
2. Double-click **Install_KPA_Bridge.command**. It asks a few short questions (press Return for yes) and installs into `RadioScripts/KPA_Bridge` in your home folder. If macOS offers to install the command line developer tools, click **Install** (not the full Xcode).
3. If the Mac says it cannot be opened, right-click the file, choose **Open**, then **Open** again. On Linux, open a terminal in that folder and type `bash Install_KPA_Bridge.command`.
4. After the install, **Change KPA Bridge Settings.command** changes the answers (amplifier address, radio kind, FlexRadio) without reinstalling.

## How to download on Windows (no GitHub account needed)

1. Install **Python 3.8 or newer** from python.org if you don't have it (tick **Add Python to PATH**).
2. Look at the **Assets** list at the bottom of this page and click **Install_KPA_Bridge.bat**. Your browser saves it, normally in your **Downloads** folder (if it warns that the file may be harmful, choose Keep).
3. Double-click it. If Windows says it protected your PC, click **More info**, then **Run anyway**. It asks a few short questions and installs into its own folder (suggested: `C:\RadioScripts`).

**Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.

The printable guide is `KPA-Bridge-guide.pdf` in Assets, and is also installed with the program as `KPA_Bridge_Help.html`.

To go back to an older version, open the [Releases page](https://github.com/kw4ex/kpa-bridge/releases) and download that one.
