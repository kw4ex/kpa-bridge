# kpa-bridge 3.0f (experimental)

**Experimental. Windows only.** The installer and helper files are Windows batch files and will not work on a Mac or Linux (those versions are still to come).

One program for your **Elecraft KPA1500** with **Thetis, Thetis HL2, SDR-VST3, NereusSDR** and a **FlexRadio running SmartSDR** (the amplifier shows up there as a Power Genius XL and a Tuner Genius XL). It brings together the earlier KPA1500 SDR Bridge and KPA1500 SmartSDR Bridge. Only one radio is on the air at a time; the amplifier follows the one in use.

**Highlights**
- The amp follows the radio that last changed frequency or transmitted. Starting SmartSDR does not move the amp away from your Thetis frequency.
- Over-drive protection for both kinds of radio, with a full-power setting for each.
- Software key that follows whichever radio transmits, including a Flex TUNE from a phone.
- Flex tuner C1/L bars, meters, quiet reconnect messages, status page at `http://127.0.0.1:8080/flex`.

Run only one bridge at a time; this one closes a running older KPA1500 bridge when it starts. Your old bridges are not changed.

## How to download (no GitHub account needed)

1. Install **Python 3.8 or newer** from python.org if you don't have it (tick **Add Python to PATH**).
2. Look at the **Assets** list at the bottom of this page and click **Install_KPA_Bridge.bat**. Your browser saves it, normally in your **Downloads** folder (if it warns that the file may be harmful, choose Keep).
3. Double-click it. If Windows says it protected your PC, click **More info**, then **Run anyway**. It asks a few short questions and installs into its own folder (suggested: `C:\RadioScripts`).

**Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.

The printable guide is `KPA-Bridge-guide.pdf` in Assets, and is also installed with the program as `KPA_Bridge_Help.html`.

To go back to an older version, open the [Releases page](https://github.com/kw4ex/kpa-bridge/releases) and download that one.
